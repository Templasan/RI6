# 📦 RI6 - Projeto Estruturado em TypeScript

Este repositório é um projeto **Node.js** com código-fonte escrito integralmente em **TypeScript**. É um projeto estruturado, ideal para exercícios ou desenvolvimento de módulos que exigem tipagem estática.

### Estrutura Principal

O repositório está organizado com os seguintes arquivos e diretórios essenciais para o fluxo de trabalho Node/TS:

  * `src/`: Contém todo o código-fonte em TypeScript (`.ts`).
  * `package.json`: Define as dependências do projeto e os scripts de execução (build, start, etc.).
  * `tsconfig.json`: Configurações do compilador TypeScript, ditando como o código TS deve ser convertido para JS.
  * `package-lock.json`: Garante que as dependências sejam instaladas com as versões exatas.

## 🔧 Como Configurar e Rodar Localmente

Para clonar, instalar e executar o projeto, siga os passos abaixo:

```bash
# 1. Clone o repositório
git clone https://github.com/Templasan/RI6.git

# 2. Vá para o diretório
cd RI6

# 3. Instale as dependências definidas no package.json
npm install

# 4. Compile o TypeScript (gera o código JavaScript na pasta de saída)
npm run build 

# 5. Execute o projeto
npm run start 
```
